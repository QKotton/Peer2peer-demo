# Thư mục file tài liệu mẫu

Đặt file PDF / ảnh / Word / PowerPoint vào đây, rồi khai báo tên file trong `src/data/taiLieuConfig.ts`.

- Đặt tên file không dấu, không khoảng trắng, vd `tom-tat-kinh-te-luong.pdf`.
- Mỗi file tối đa 25 MB (giới hạn upload qua giao diện web GitHub).
- Repo đang để công khai: chỉ đưa lên tài liệu nhóm tự soạn, không dùng slide / giáo trình / đề thi của giảng viên.
